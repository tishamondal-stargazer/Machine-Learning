# Extra Practical 10: Hierarchical Clustering (Spotify Dataset)

## Aim
To perform Hierarchical Clustering using agglomerative methods and interpret dendrograms for cluster formation.

## Objective
- Understand hierarchical clustering techniques.
- Apply agglomerative clustering on Spotify dataset.
- Analyze relationships between songs based on features.
- Interpret dendrograms for cluster formation.

## Description
This practical demonstrates the use of Hierarchical Clustering on the Spotify Songs dataset. The dataset contains multiple features related to songs such as tempo, energy, loudness, and danceability.

The algorithm groups similar songs into clusters based on these attributes. Dendrograms are used to visualize the hierarchical structure and determine optimal clusters.

The notebook includes the following steps:

- Importing required libraries such as NumPy, Pandas, Matplotlib, and SciPy
- Loading dataset from GitHub
- Data preprocessing and feature selection
- Creating dendrograms
- Applying Agglomerative Clustering
- Visualizing clusters
- Interpreting results

This practical helps in understanding clustering for recommendation systems and music analysis.

## Dataset
Spotify Songs dataset (loaded from GitHub)

- Google Colab
