Practical 03 Extra – Logistic Regression on Diabetes Dataset

Aim  
To implement Logistic Regression on the Diabetes Prediction dataset and evaluate classification performance.

Description  
This practical demonstrates the application of Logistic Regression on the Diabetes Prediction dataset to classify whether a patient is diabetic or not.

The dataset contains various medical features such as glucose level, blood pressure, BMI, insulin level, and age. Logistic Regression is used to model the probability of diabetes occurrence based on these features.

The workflow includes:

• Importing necessary libraries such as NumPy, Pandas, Matplotlib and Scikit-learn  
• Loading the Diabetes dataset from the dataset source  
• Performing data preprocessing including handling missing values and feature scaling  
• Splitting the dataset into training and testing sets  
• Training the Logistic Regression model  
• Making predictions on test data  
• Evaluating model performance using confusion matrix and accuracy score  
• Analyzing precision, recall, and F1-score  

This practical helps understand how Logistic Regression can be applied to real-world healthcare datasets for classification problems.
