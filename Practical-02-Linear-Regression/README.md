Practical 02

Aim:
To implement the Linear Regression algorithm for predicting continuous target variables and evaluate the model performance using appropriate evaluation metrics.

Objective:
• Understand the concept of supervised learning for regression problems.
• Learn how Linear Regression models relationships between independent and dependent variables.
• Implement Linear Regression using Python machine learning libraries.
• Evaluate model performance using suitable regression metrics.

Description:
This practical demonstrates the implementation of the Linear Regression algorithm for solving regression problems in machine learning. Linear Regression is one of the fundamental supervised learning algorithms used to model the relationship between input features and a continuous target variable.

The experiment begins with loading and exploring the dataset followed by basic data preprocessing. The dataset is then divided into training and testing subsets to evaluate the model's predictive capability on unseen data.

The notebook includes the following steps:

• Importing required Python libraries such as NumPy, Pandas, Matplotlib and Scikit-learn  
• Loading and exploring the dataset  
• Performing data preprocessing and feature selection  
• Splitting the dataset into training and testing sets  
• Training the Linear Regression model using Scikit-learn  
• Generating predictions for the test dataset  
• Evaluating model performance using regression metrics such as Mean Absolute Error (MAE), Mean Squared Error (MSE) and R² Score  
• Visualizing the regression line and analyzing model predictions

This practical provides a strong foundation for understanding regression models and prepares students to apply machine learning techniques for predictive analysis in real-world datasets.

Tools Used:
