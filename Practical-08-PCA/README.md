Practical 08 – Principal Component Analysis (PCA)

Aim  
To apply Principal Component Analysis for dimensionality reduction and visualize the transformed feature space.

Description  
This practical demonstrates the implementation of Principal Component Analysis (PCA) using Python. PCA is an unsupervised dimensionality reduction technique used to transform high-dimensional data into a lower-dimensional space while retaining maximum variance.

In this experiment, the Iris dataset is used. The dataset contains multiple features such as sepal length, sepal width, petal length, and petal width.

The workflow includes:

• Importing necessary libraries such as NumPy, Pandas, Matplotlib and Scikit-learn  
• Loading the Iris dataset using Scikit-learn  
• Standardizing the dataset to normalize feature values  
• Applying PCA to reduce dimensions to 2 principal components  
• Visualizing the transformed data using scatter plots  
• Analyzing explained variance ratio of principal components  

PCA helps in reducing complexity, improving visualization, and removing multicollinearity from the dataset.

Tools Used  
Python  
Google Colab  
Scikit-learn  
Matplotlib

Sample Output
