# Extra Practical 06 – ANN for Heart Failure Prediction

## Aim
To design and implement an Artificial Neural Network for a classification problem and evaluate its learning performance.

## Objective
- Apply ANN on a healthcare dataset
- Learn how neural networks detect medical patterns
- Evaluate classification performance

## Theory

Artificial Neural Networks are widely used in healthcare for predictive analysis. They can identify hidden relationships between patient features and outcomes.

ANN consists of:
- Input Layer (patient features)
- Hidden Layers (pattern learning)
- Output Layer (prediction)

## Description

In this practical:
- Heart Failure dataset is loaded
- Data preprocessing is performed
- Dataset is split into training and testing sets
- ANN model is built and trained
- Predictions are generated
- Model performance is evaluated

## Steps Performed

1. Load dataset
2. Perform preprocessing
3. Apply feature scaling
4. Split dataset
5. Build ANN model
6. Train model
7. Predict results
8. Evaluate model

## Tools Used
- Python
- TensorFlow / Keras
- Scikit-learn
- Pandas, NumPy

## Output

- Model accuracy
- Classification report
- Prediction results

## Conclusion

ANN models are highly effective for healthcare prediction tasks, helping in early diagnosis and decision-making.
