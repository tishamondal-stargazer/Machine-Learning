Aim:
Understanding the Google Colab environment and exploring commonly used Python libraries for Machine Learning.

Libraries Used:
NumPy  
Pandas  
Matplotlib  
Seaborn  
Scikit-learn  

Description:
This practical introduces the Google Colab environment and demonstrates how Python libraries are used for data analysis and machine learning tasks. Google Colab is a cloud-based platform that allows users to write and execute Python code through a web browser without requiring local software installation.

In this experiment, several widely used libraries in the machine learning ecosystem are explored. NumPy is used for numerical computations and handling multidimensional arrays. Pandas is utilized for data manipulation and analysis, enabling structured data handling through DataFrames. Matplotlib and Seaborn are used for data visualization, allowing graphical representation of data patterns and trends.

The notebook also introduces Scikit-learn, a powerful machine learning library that provides tools for data preprocessing, model building, and evaluation.

The main workflow demonstrated in this practical includes:

• Introduction to the Google Colab environment  
• Importing and using Python libraries for machine learning  
• Performing basic numerical computations using NumPy  
• Handling and analyzing datasets using Pandas  
• Visualizing data using Matplotlib and Seaborn  
• Understanding how machine learning libraries support model development  

This practical provides the foundational understanding required to work with Python-based machine learning tools and prepares students for implementing machine learning algorithms in subsequent experiments.
