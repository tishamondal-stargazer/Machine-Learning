# Extra Practical 05 – Random Forest on Gaming & Mental Health Dataset

## Aim
To implement the Random Forest algorithm on the Gaming and Mental Health dataset and evaluate the model performance.

## Objective
- Apply Random Forest on real-world dataset
- Understand relationship between gaming behavior and mental health
- Evaluate classification performance

## Theory

Random Forest uses multiple decision trees to improve prediction accuracy and stability.

It is especially useful for:
- Complex datasets
- Non-linear relationships
- Feature importance analysis

## Description

In this practical:
- Gaming & Mental Health dataset is loaded
- Data preprocessing and cleaning is performed
- Random Forest classifier is trained
- Predictions are made
- Model performance is evaluated

## Steps Performed

1. Load dataset
2. Clean and preprocess data
3. Split dataset
4. Train Random Forest model
5. Predict results
6. Evaluate performance

## Tools Used
- Python
- Scikit-learn
- Pandas, NumPy

## Output

- Accuracy score
- Confusion matrix
- Classification report

## Conclusion

Random Forest performs well on real-world datasets by handling complex patterns and reducing overfitting, making it suitable for behavioral analysis tasks.
