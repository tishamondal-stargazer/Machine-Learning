# Practical 12: Regression Post Lab (Housing Dataset)

## Aim
To implement a complete regression problem by performing data preprocessing, model building, evaluation, and result interpretation.

## Objective
- Understand complete machine learning workflow
- Perform data preprocessing and feature engineering
- Apply multiple regression models
- Evaluate and compare model performance
- Interpret results for prediction accuracy

## Dataset
Housing Dataset (housing.csv)

## Features
- Longitude
- Latitude
- Housing Median Age
- Total Rooms
- Total Bedrooms
- Population
- Households
- Median Income
- Ocean Proximity (categorical)

## Target Variable
- Median House Value (median_house_value)

## Description
This practical demonstrates a complete regression pipeline using the Housing dataset. The dataset contains both numerical and categorical features, making it suitable for real-world machine learning implementation.

Steps performed:
- Data loading from GitHub
- Data exploration (head, info, describe)
- Handling missing values
- Encoding categorical features
- Feature scaling
- Train-test split (80:20)
- Model training and prediction
- Evaluation using MAE, MSE, R² Score
- Model comparison

## Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Tools Used
- Python
- Google Colab
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

Random Forest Regressor generally provides better accuracy compared to other models due to its ensemble learning capability.
