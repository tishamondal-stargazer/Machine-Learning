# Extra Practical 09: K-Means Clustering (Wine Dataset)

## Aim
To implement the K-Means clustering algorithm and analyze clustering results using appropriate evaluation techniques.

## Objective
- Understand clustering using K-Means algorithm.
- Apply clustering on real-world Wine dataset.
- Identify patterns based on chemical properties of wine.
- Evaluate clusters using metrics like Inertia and Silhouette Score.

## Description
This practical demonstrates the use of the K-Means clustering algorithm on the Wine Quality dataset, which contains 13 chemical features of different wine samples.

The dataset is used to group wines into clusters based on similarities in their chemical composition. This helps in identifying different wine types and quality segments.

The notebook includes the following steps:

- Importing required libraries such as NumPy, Pandas, Matplotlib, and Scikit-learn
- Loading dataset from GitHub
- Data preprocessing and feature selection
- Applying Elbow Method to find optimal number of clusters
- Training K-Means clustering model
- Visualizing clusters
- Evaluating clustering performance using Inertia and Silhouette Score

This practical helps in understanding clustering in chemical and quality analysis applications.

## Dataset
WineQT dataset (loaded from GitHub)
