# Practical 09: K-Means Clustering

## Aim
To implement the K-Means clustering algorithm and analyze the clustering results using appropriate evaluation techniques.

## Objective
- Understand the concept of unsupervised learning and clustering.
- Learn how K-Means groups similar data points into clusters.
- Determine the optimal number of clusters using the Elbow Method.
- Evaluate clustering performance using metrics like Inertia and Silhouette Score.

## Description
This practical demonstrates the implementation of the K-Means clustering algorithm for grouping similar data points into clusters. K-Means is an unsupervised learning technique widely used for customer segmentation, pattern recognition, and data analysis.

The experiment begins with loading and exploring the dataset (Mall Customers dataset), followed by data preprocessing and feature selection. The dataset is then used to apply clustering techniques.

The notebook includes the following steps:

- Importing required Python libraries such as NumPy, Pandas, Matplotlib, and Scikit-learn
- Loading and exploring the dataset
- Selecting relevant features for clustering
- Using the Elbow Method to determine the optimal number of clusters
- Training the K-Means clustering model
- Visualizing clusters using scatter plots
- Evaluating clustering performance using Inertia and Silhouette Score

This practical helps in understanding how clustering works in real-world scenarios like customer segmentation and market analysis.

## Dataset
Mall_Customers dataset (loaded from GitHub)
