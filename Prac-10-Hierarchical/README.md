# Practical 10: Hierarchical Clustering

## Aim
To perform Hierarchical Clustering using agglomerative methods and interpret dendrograms for cluster formation.

## Objective
- Understand hierarchical clustering concepts.
- Learn agglomerative clustering technique.
- Interpret dendrograms to identify cluster structures.
- Compare hierarchical clustering with K-Means clustering.

## Description
This practical demonstrates the implementation of Hierarchical Clustering using agglomerative methods. It is an unsupervised learning technique used to group similar data points into clusters without predefining the number of clusters.

The experiment begins with loading and exploring the dataset (Mall Customers dataset), followed by preprocessing and feature selection. A dendrogram is used to visualize cluster formation and determine the optimal number of clusters.

The notebook includes the following steps:

- Importing required libraries such as NumPy, Pandas, Matplotlib, and SciPy
- Loading and exploring the dataset
- Feature selection and preprocessing
- Creating dendrograms to visualize cluster hierarchy
- Applying Agglomerative Clustering
- Visualizing clusters
- Interpreting clustering results

This practical provides insight into hierarchical relationships in data and helps understand clustering without predefining cluster numbers.

## Dataset
Mall_Customers dataset (loaded from GitHub)

- Python
- Google Colab
