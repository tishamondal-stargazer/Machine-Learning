Extra Practical 02

Aim:
To implement Linear Regression on the Insurance dataset to predict insurance charges based on multiple input features and evaluate the model performance.

Objective:
• Understand the application of Linear Regression on real-world datasets  
• Learn how different features influence insurance cost prediction  
• Perform data preprocessing and feature selection  
• Train and evaluate a regression model using machine learning techniques  

Description:
This extra practical focuses on applying the Linear Regression algorithm to a real-world Insurance dataset for predicting insurance charges. Linear Regression is a fundamental supervised learning technique used to model relationships between dependent and independent variables.

The experiment begins with loading and exploring the dataset to understand the features such as age, BMI, smoking status, and region, which influence the insurance cost. Data preprocessing techniques are applied to handle categorical variables and prepare the dataset for modeling.

The dataset is then divided into training and testing subsets to evaluate how well the model performs on unseen data. A Linear Regression model is implemented using Scikit-learn, which learns the relationship between input features and the target variable.

The notebook includes the following steps:

• Importing required Python libraries such as NumPy, Pandas, Matplotlib and Scikit-learn  
• Loading and exploring the insurance dataset  
• Performing data preprocessing including encoding categorical variables  
• Splitting the dataset into training and testing sets  
• Training the Linear Regression model  
• Generating predictions on test data  
• Evaluating model performance using regression metrics such as Mean Absolute Error (MAE), Mean Squared Error (MSE) and R² Score  
• Visualizing results to analyze model predictions  

This practical helps in understanding how regression models can be applied to real-world problems such as cost prediction and provides hands-on experience in building and evaluating machine learning models.
