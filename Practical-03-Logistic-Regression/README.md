Practical 03 – Logistic Regression Classification

Aim  
To implement Logistic Regression for binary or multiclass classification problems and analyze the classification performance.

Description  
This practical demonstrates the implementation of the Logistic Regression algorithm for classification tasks using Python. Logistic Regression is a supervised machine learning algorithm used to predict categorical outcomes based on input features.

In this experiment, a dataset is used to classify data into different categories using probability-based decision boundaries. Logistic Regression models the relationship between dependent and independent variables using a logistic (sigmoid) function.

The workflow includes:

• Importing required Python libraries such as NumPy, Pandas, Matplotlib and Scikit-learn  
• Loading and exploring the dataset  
• Performing data preprocessing and feature selection  
• Splitting the dataset into training and testing sets  
• Training the Logistic Regression model using Scikit-learn  
• Generating predictions on test data  
• Evaluating model performance using confusion matrix and accuracy score  
• Calculating performance metrics such as precision, recall, and F1-score  

Logistic Regression provides probabilistic outputs and helps in understanding class membership based on a threshold value.
